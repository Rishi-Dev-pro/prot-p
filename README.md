# Rishi Kumar Shaw — Agentic-Style Developer Portfolio

A futuristic, highly interactive personal developer portfolio for **Rishi Kumar Shaw** featuring a scripted simulation of 20 autonomous AI agents constructing the digital environment in real-time.

> **Architecture Principle:** Recreating the visual spectacle of real-time multi-agent website synthesis without runtime AI API overhead or server-side latency. The site is pre-built, responsive, and 100% functional.

---

## 🌟 Key Highlights

- **Scripted Agent Construction (The Defining Feature):** Approximately 20 distinct simulated agent cursors (`AGENT_01` to `AGENT_20`) with unique palettes, pointers, roles, and real-time activity telemetry collaboratively assemble the interface step-by-step.
- **Skip & Reduced-Motion Support:** Includes a visible `SKIP INTRO [ESC]` trigger and fully respects `prefers-reduced-motion` settings.
- **Interactive System Architecture Graph:** A custom SVG ecosystem topology connecting the central `RISHI — ENGINEERING ECOSYSTEM` node with 6 core domains (`Frontend Engineering`, `Backend Systems`, `Artificial Intelligence`, `Computer Vision`, `Database Architecture`, and `Automation & Integration`) with interactive node inspection and animated telemetry rays.
- **Editorial Flagship Projects:**
  1. **AHI (Adaptive Human Interface):** Contextual observation & SQLite-backed persistent knowledge synthesis.
  2. **AETHER OS:** AI-driven computer vision desktop task automation platform.
  3. **PIRATE-CIV:** Domain-driven island marketplace with 695/695 milestone test passes (Phases 3.1–3.6).
  4. **CAMPUSRESOLVE:** MERN-stack administrative campus workflow platform.
  5. **CALLBUDDY AI:** Multi-modal shared AI room and calling platform R&D.
  6. **EDGE AI — Pothole Detection:** Offline road perception on Arduino UNO Q with YOLOv8n.
- **Honest Engineering Records:** Absolutely zero fabricated client revenue, fake certificates, or inflated skill progress bars.
- **Performance:** Clean 60 FPS transitions, modular architecture, full TypeScript strictness, and sub-second production builds.

---

## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4 with custom dark futuristic design tokens
- **Animations:** Framer Motion & GSAP
- **Icons:** Lucide React + custom SVG marks
- **Typography:** Space Grotesk, Inter, and JetBrains Mono
